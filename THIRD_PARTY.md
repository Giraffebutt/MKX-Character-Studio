These are installed by the user, not bundled:

- Python and Tcl/Tk: [Python license](https://docs.python.org/3/license.html), [Tcl/Tk license](https://www.tcl-lang.org/software/tcltk/)
- NumPy: [BSD-3-Clause](https://github.com/numpy/numpy/blob/main/LICENSE.txt)
- Pillow: [MIT-CMU](https://github.com/python-pillow/Pillow/blob/main/LICENSE)

The repository is intended to contain only original project source code and properly licensed third-party components. No Mortal Kombat X source code or decompiler output is intended to be included. `lzo1x.py` decodes the LZO1X compression format (created by Markus F.X.J. Oberhumer), which original game packages use.

The tool reads and writes the game's file format for interoperability. It contains no game code, data, executables or keys. Mortal Kombat and its characters belong to their respective owners.
