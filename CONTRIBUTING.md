# Contributing

Keep this repository free of game content and other people's work:

- No game files or anything extracted from them: packages (`.xxx`, `.tfc`), exported `.glb` files, textures, skeletons, audio or screenshots.
- No game executables, symbol files, DLLs, keys or decompiler output. Write code from your understanding of the format; don't copy code.
- No third-party characters or assets unless you have the right to share them.
- No personal paths, logs, settings or mod-folder contents (`converted`, `vanilla_exports`, `vanilla_cache`).
- Tests must use synthetic data only.

`.gitignore` is an allowlist, so add each new source file to it on purpose.

Use, modification, and redistribution are permitted for noncommercial purposes, subject to the full license terms. Include the license terms or their URL and any required notices when redistributing.

By submitting a contribution, you confirm that you have the right to submit it and that it does not contain copied game code, decompiler output, or third-party code incompatible with this project's license.
